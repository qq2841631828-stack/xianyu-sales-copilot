# 聊单方法

## 核心原则

用尽量少的无效来回把需求和约定聊清楚。先接住客户当下的话，再判断是否需要补信息；确认、致谢和等待也可以是合理结束，不要求每条回复都提问或安排下一步。以下判断在内部完成，用户要求分析时才展开。

## 六步判断法

1. **还原事实**：识别说话人、时间顺序、客户最后的问题、已经明确的范围和卖家真正发出的内容。
2. **判断阶段**：区分初询、澄清、范围确认、报价、议价、待付款、履约、验收、售后和复购。
3. **找主要阻碍**：在信息不足、能力不明、预算差异、时间风险、信任顾虑和范围争议中只选当前最关键的一项。
4. **按需补问**：先正面回答客户，仅在缺失信息影响本轮答复时问一个关键问题，已知的不再问。
5. **形成闭环**：复杂项目在报价前内部核对交付物、包含与不包含、客户材料、时间节点、验收和修改边界，缺什么再逐步确认。
6. **判断收尾**：需要推进时给一个自然动作；没有待办时允许简短确认、等待，或建议卖家暂时不用回。

## 阶段与当前动作

| 阶段 | 直接证据 | 当前动作 |
|---|---|---|
| 初次咨询 | 客户只问能否做、价格、案例或时间 | 先答问题，缺少关键条件时再问一个 |
| 需求澄清 | 已有目标，但交付物或材料不清 | 用客户语言复述，并补最关键缺口 |
| 范围确认 | 交付物基本明确，仍有边界差异 | 给简短范围确认卡，请客户确认 |
| 待报价 | 范围和时间基本齐全 | 使用卖家本次已批准的金额起草；尚无金额时只提醒卖家定价，不继续盘问客户 |
| 已报价/议价 | 卖家已确认报价发出，客户谈预算 | 找出差异点，解释范围或缩小方案 |
| 待付款确认 | 客户说要付或发了凭证 | 提醒卖家核实，不写“已到账” |
| 履约 | 卖家确认合作并实际开始 | 只汇报可核实节点，管理下一确认点 |
| 验收修改 | 客户针对成品提出意见 | 对照原范围，拆成原范围修改与新增需求 |
| 售后 | 明确投诉、退款或严重不满 | 先接住具体问题，再核对事实和给选项 |
| 复购 | 历史客户带来新需求 | 保留信任，但重新确认本次范围、时间和价格 |

没有直接证据时，不把阶段写成事实。例如客户说“好的”只能说明暂时认可当前一句话，不能据此判断成交或付款，也不需要借机催付。若前文仍有未答问题或行动要求，应结合该上下文处理。

## 回复写法

- 开头直接回应客户的疑问，避免先讲品牌、资历或长篇流程。
- 仅在澄清歧义或锁定范围时简短复述，保留客户用词，不替客户扩大目标。
- 问法像日常聊天，例如“这份大概多少页？”；只有客户可能不理解时，再解释为什么需要这项信息。
- 用具体交付物替代“高质量”“精美”“全包”等抽象词。
- 时间、进度和承诺必须有依据；内部的“待确认”不要原样放进客户话术。
- 语气跟随客户的正式程度，不固定使用“姐姐、宝宝、老板”等称呼。
- 不靠贬低同行、夸大资历、虚构案例或绝对承诺建立信任。

## 连续聊天与条件沿用

- 同一客户的连续截图去重后合并阅读，先查前文是否已经回答，不只看最后一张图。
- 卖家本次明确给出的金额、排期和范围，以及截图清楚显示卖家已发出的条件，可直接用于后续草稿。不要再次要求同样的批准；持久化台账状态仍遵循工作流中的卖家确认要求。
- 仅卖家提供金额但未说明已发出时，不把报价状态记为已发送。AI 自己起草的条件仍未获批准。
- 新截图出现范围变更或条件冲突时，核对差异；客户要求降价不等于卖家同意降价。切换客户或新订单时，不自动沿用旧条件。

## 简短示例

以下只示范在给定事实下如何接话，不是固定模板。

- 客户问 PPT 多少钱，页数和材料都未知：可以回“主要看页数和内容量，你这份大概多少页？”不连着追问用途、预算和截止时间。
- 同一客户本次已确认“20 页排版，300 元”，客户问“多少钱来着”：可以回“这份 20 页排版是 300 元。”不重新询问页数，不再向卖家索价。
- 客户嫌贵，包含内容已解释、预算仍未知：可以回“你大概想控制在多少预算？我看看有没有能精简的部分。”不擅自答应优惠。
- 客户说“好的谢谢”，前文没有未答问题或待办：可建议卖家“这句可以先不用回。”不追加催单话术。

## 复杂项目闭环

出现多文件、多阶段、长周期、多人审核或涉密内容时，内部先整理：

- 背景与使用场景
- 客户真正要解决的问题
- 交付物及格式
- 包含与不包含
- 客户需提供的材料和时间
- 中途确认节点与验收依据
- 截止时间、修改边界和依赖条件
- 价格与付款安排：待卖家确认

先用不涉密摘要判断能力和工作量。若服务陌生，坦白需要评估，索取样例或关键词；不要为了成交先承诺。

## 从历史分析中采用的结论

本方法参考了分析目录中的 43 组聊单模式诊断、81 组售后案例和 60 组复购案例。样本显示：历史沟通中关系维护和提问很多，但明确“下一步”的表达偏少；多起退款与范围未锁定、预期未对齐、进度失真或数据不可复现有关；复购更依赖及时响应、可靠交付、稳定质量和省心，而不是统一降价。

这些是历史观察，不是因果结论或当前政策。不得复制样本中的客户身份、历史金额、私域迁移、好评激励、自动优惠、固定退款阈值、学术违规做法或侮辱性标签。
